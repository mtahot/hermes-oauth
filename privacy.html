Privacy policy

HermesAgent — last updated 10 November 2026

HermesAgent is a private, single-user application. It is operated by its owner on a private server and is not distributed to, or used by, any third party. This policy describes how the application handles Google user data.

Data accessed

With the account owner's explicit consent, and only for their own account, the application may access:

  • Gmail (gmail.readonly, gmail.send) — to read incoming messages and send replies on the owner's behalf.
  • Google Calendar — to read and manage the owner's events.
  • Google Drive — to store and retrieve files the owner chooses to archive, such as generated reports.
  • Google Tasks — to read and update the owner's task lists.
  • Google Contacts — to look up the owner's own contacts.

How data is used

Data is used solely to perform the tasks the owner requests (summarising mail, scheduling events, archiving reports, tracking tasks). It is never used for advertising, profiling, or any commercial purpose.

Storage and retention

OAuth tokens and any cached content are stored locally on the owner's private server, protected by filesystem permissions. Data is retained only as long as needed for the feature that produced it, and the owner can delete it at any time.

Sharing

No Google user data is sold, rented, transferred, or disclosed to any third party, except where strictly required by law. No third-party analytics or advertising services are used.

Google API Services User Data Policy

HermesAgent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Revocation takes effect immediately.
